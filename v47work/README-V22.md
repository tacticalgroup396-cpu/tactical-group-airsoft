# Tactical Group Airsoft V22

- Cards de equipe/comandantes exibem a foto do operador e botão Ver perfil.
- Cada jogo tem Elo por participação definido pelo comandante (mínimo 1).
- O Elo é concedido quando o comandante registra o operador como presente.
- Cada presença concede o Elo configurado no jogo.
- A cada 3 Elos, o operador sobe 1 patente; Elo excedente permanece.
- Cada presença concede Elo uma única vez por jogo.
