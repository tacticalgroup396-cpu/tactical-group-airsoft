# Tactical Group Airsoft V15

Correções e regras integradas:
- Perfil/painel do Comandante preservado, incluindo o comandante principal.
- Comandante principal pode promover operadores a comandantes e remover o comando de outros comandantes.
- Convite excluído remove o cadastro pendente da equipe.
- Operador pode marcar **Vou**, **Não vou** ou **Desmarcar**.
- Jogo possui prazo limite de confirmação por data e hora.
- Após o prazo, se o mínimo não for atingido, o jogo passa para cancelado automaticamente.
- Vercel Cron verifica os prazos a cada 5 minutos.
- Operador recebe informações do prazo no jogo.
- Notificações internas e Web Push continuam integrados.

Commit sugerido:
Corrige perfil do comandante, presença e prazo dos jogos
