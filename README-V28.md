# Tactical Group Airsoft V28

- Operador confirma presença somente com **Vou** ou **Não vou**.
- A resposta pode ser alterada depois: quem marcou **Vou** pode voltar e marcar **Não vou** (e vice-versa) até o prazo.
- Removida a opção **Desmarcar** da interface de jogos.
- Loadout de cada jogo usa **AEG secundária** no lugar de Réplica usada.
- Botão **+** permite adicionar vários equipamentos extras para levar no jogo.
- Equipamentos adicionais são salvos no JSON do loadout sem nova migração do banco.
